# Back Chat

[![NuGet](https://img.shields.io/nuget/vpre/Umbraco.Community.BackChat?color=0273B3)](https://www.nuget.org/packages/Umbraco.Community.BackChat)

Chat, tasks and review dates for the Umbraco backoffice, for Umbraco 17. See the [package readme](docs/README_nuget.md) for what it does.

## Building

Requirements: .NET SDK 10 (see `global.json`) and Node 24.

```
cd src/BackChat/Client
npm ci
npm run build
```

`npm run build` writes the bundle to `src/BackChat/wwwroot/App_Plugins/BackChat`. Then build the package:

```
dotnet build src/BackChat/BackChat.csproj -c Release
```

### The API client

Tasks, reviews and the dashboard call BackChat's Management API through a client generated by hey-api into `src/BackChat/Client/src/api`. The generated files are committed. After changing a controller, run a site with the package, then regenerate:

```
cd src/BackChat/Client
npm run generate-client
```

The script reads the swagger document from `https://localhost:54689/umbraco/swagger/backchat/swagger.json`. Change the port in `package.json` to match your site.
